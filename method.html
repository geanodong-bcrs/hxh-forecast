How this works
and where it is weakest

The question

Hunter × Hunter has not been a weekly series since 2006. It comes out in runs of about ten chapters, separated by breaks that have ranged from nothing at all to three and a half years. Within a run, chapters appear one per week almost without exception — 143 of the last 145 gaps were exactly one issue.

So there is really only one hard question: when does the next run start? Everything else follows from it, which is why the ten-chapter tables are so tightly bunched.

The three levels

0 — already announced

If Shueisha has named the issue, there is nothing to predict. That chapter is recorded as scheduled and drops out of the model.

1 — what history alone suggests

Built from publication records only, never from Togashi’s posts — otherwise the next step would not be an update. There are 16 gaps between runs since 2007, and they are bimodal: three times the next run began with no wait at all, the rest after waits of 9 to 184 issues. A single smooth curve would describe neither case, so the model uses a mixture.

2 — what Togashi’s posts add

Production data covers only 3 past runs. That is far too few to fit a curve to, but enough to ask a different question: if this run behaves like that one, when would it start? Each past run is replayed onto the current production dates.

If it behaves like……chapter 421 comes out
the run starting at chapter 39127 Aug 2026
the run starting at chapter 4018 Aug 2026
the run starting at chapter 41125 Jan 2027

Two of the three point at a date that has already passed. That is informative — it means this run is not behaving like them.

Putting them together

Togashi has posted 28 production updates about this run. Those are not 28 independent pieces of evidence — they are one person’s working process observed 28 times. Treating them as independent would produce a forecast about a week wide: very impressive, and wrong. So each past run counts once, and the confidence scales with how many comparable runs exist (three), not how many posts there are.

Where it is weakest

The headline number is the least defensible part

The 50.6% on 14 Sep 26 comes from a point mass estimated from two clustered observations from 2010–2012. It says there is roughly an even chance the series rolls straight from this run into the next with no break — which has not actually happened since 2012. It survived every check I ran, and it is still the claim I would least want to defend.

  1. The production side has never been scored against a real outcome. Three comparable runs, and none has started since the method was built. Chapter 421 will be the first genuine test.
  2. No accuracy figures are published. Scoring honestly means separating forecasts made before an official announcement from those made after, and that record has not been built yet. Without the split the numbers would measure how early Shueisha announces things, not whether this model knows anything. They are left out rather than estimated.
  3. The date slides later every week nothing happens. Once an issue passes without a chapter, that possibility is removed and the rest rescales. This is correct, but it will look like the model changing its mind.
  4. Chapters 431–440 rest on history alone. The only production events reported for them are at the earliest stage, which says nothing about scheduling.
  5. Where this run ends is assumed, not confirmed. A post from April 2026 can be read as “chapter 420 onward”, which would shift everything by ten chapters.
  6. Both publication sources are secondary. Nothing has been checked against Shueisha directly.
